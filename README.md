# 💊 AI-Driven Drug Alert System

An AI-powered drug safety system that analyzes prescriptions and patient information to identify potential **drug interactions, dosage risks, allergies, and patient-specific safety concerns**.

## 🚀 Live Demo

**[View Live Project](YOUR_LIVE_DEMO_LINK)**

## ✨ Features

- 👤 Patient profile management
- 💊 Prescription and medicine management
- ⚠️ Drug-drug interaction detection
- 🧪 Allergy and contraindication checks
- 📊 Patient-specific safety analysis
- 💡 Dosage and age-related risk alerts
- 🤖 AI-powered drug safety assistant
- 📄 Downloadable safety reports

## 🛠️ Technologies Used

**Frontend:** React.js, Vite, Tailwind CSS  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**AI/ML:** Python, FastAPI, Scikit-learn, XGBoost, MLP  
**Other:** RDKit, FAISS, JWT, OpenRouter

## 🧠 AI & Safety Analysis

The system combines machine learning with rule-based safety checks to analyze drug interactions and prescription risks based on factors such as:

- Patient age and medical conditions
- Current medicines
- Allergies
- Dosage and frequency
- Known drug interactions

The system provides understandable explanations of detected safety concerns through its AI assistant.

## 📌 Project Purpose

DrugAlert is an academic decision-support prototype demonstrating how **AI, machine learning, and healthcare data** can be combined to improve prescription safety and provide understandable drug-related alerts.

> **Note:** This project is an academic prototype and is not intended to replace professional medical advice.
