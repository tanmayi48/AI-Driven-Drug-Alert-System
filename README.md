# 💊 AI-Driven Drug Alert System

An AI-powered drug safety system that analyzes prescriptions and patient information to identify potential **drug interactions, dosage risks, allergies, contraindications, and patient-specific safety concerns**.


## ✨ Features

- 👤 Patient profile management
- 💊 Prescription and medicine management
- 🔎 Medicine search from drug database
- ⚠️ Drug-drug interaction detection
- 🧪 Allergy and contraindication checks
- 📊 Patient-specific safety analysis
- 💡 Dosage and age-related risk alerts
- 🤖 AI-powered drug safety assistant
- 📄 Downloadable safety reports

## 🧠 How It Works

The system analyzes **patient information and prescription details** together to identify potential safety concerns.

The analysis considers:

- Patient age and medical conditions
- Current medicines
- Allergies and medical history
- Dosage information
- Known drug interactions

The system combines **machine learning models and rule-based safety checks** to generate risk alerts and understandable explanations.

## 🤖 AI & Machine Learning

The project uses multiple approaches for drug safety analysis:

- **Logistic Regression** – Baseline classification model
- **XGBoost** – Machine learning classification
- **MLP** – Neural-network-based classification
- **Rule-based checks** – Dosage, allergy, age, and contraindication alerts
- **AI assistant** – Provides explanations for drug-related safety concerns

## 🛠️ Technologies Used

**Frontend:** React.js, Vite, Tailwind CSS  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**AI/ML:** Python, FastAPI, Scikit-learn, XGBoost, MLP  
**Drug/Data Processing:** RDKit, FAISS  
**Authentication & AI:** JWT, OpenRouter  
**Tools:** Git, GitHub, VS Code, Postman

## 📌 Project Purpose

DrugAlert is an **academic decision-support prototype** demonstrating how **AI, machine learning, and healthcare data** can be combined to support prescription safety analysis and provide understandable drug-related alerts.

> **Note:** This project is an academic prototype and is not intended to replace professional medical advice.
