# DrugAlert — AI Driven Drug Alert System

Rebuilt from the three-page final project guidelines. React/Vite/Tailwind frontend, Node/Express/JWT backend, MongoDB, Python/FastAPI, real DDInter/SIDER/PubChem preprocessing, three-model comparison, RDKit features, FAISS evidence retrieval, optional OpenRouter explanations and downloadable PDF reports.

## Run on Windows

Requires Node 20+, Python 3.9+ (3.11 recommended), MongoDB running locally or an Atlas URI.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
npm install
Copy-Item .env.example .env # only if .env does not already exist
# Set JWT_SECRET and AI_INTERNAL_SECRET to separate random 32+ character values.
# Set MONGODB_URI if using Atlas. Optional: add OPENROUTER_API_KEY.
npm run seed
npm run import:data
.\start.ps1
```

Open http://localhost:5173. Register your own account (password at least 10 characters). No shared default account. Add a fictional patient, select medicines, analyze, download PDF and ask the evidence assistant. API runs on port 4000, AI service on 8000. The root `.env` created during this build already contains generated local secrets; keep it private.

`app.py` now launches only the new AI service. The complete application uses `start.ps1`.

## API keys and configuration

| Variable | Needed for |
|---|---|
| `MONGODB_URI` | Required database connection. Local MongoDB needs no API key; Atlas URI includes database credentials. |
| `JWT_SECRET` | Required local authentication secret, generated by you or setup. Not a purchased API key. |
| `AI_INTERNAL_SECRET` | Required service-to-service authentication secret. Same root `.env` is read by both services. |
| `OPENROUTER_API_KEY` | Required for generated educational answers and evidence explanations. Without it, local evidence and a configuration notice are returned. |
| `OPENROUTER_MODEL` | OpenRouter model slug; default `nvidia/nemotron-3-ultra-550b-a55b:free`. Use a non-OpenAI model. |
| `PORT`, `AI_SERVICE_URL`, `FRONTEND_ORIGIN` | Local ports and frontend origin. |

DDInter, SIDER and PubChem pipeline does not need API keys. Never put secrets in frontend code or variables prefixed `VITE_`.

## Reproduce the data and training

```powershell
.\.venv\Scripts\python.exe scripts/download_data.py
.\.venv\Scripts\python.exe scripts/preprocess.py --max-drugs 160 --max-pairs 3000
.\.venv\Scripts\python.exe scripts/train.py
npm run import:data
```

Raw file manifest includes source URLs, retrieval dates and SHA-256 hashes. Preprocessing removes missing IDs, reversed/duplicate pairs, conflicting labels and unknown severity; maps SIDER flat PubChem IDs, enriches structures through PubChem, and creates the MongoDB import and RAG corpus. Sampling is a bounded high-degree connected subset, explicitly recorded in metadata. Increase sample size for stronger evaluation.

Training compares balanced Logistic Regression, weighted XGBoost and an MLP with training-only balanced bootstrap. Unique unordered-pair 60/20/20 split prevents reversed-pair leakage; selection uses validation macro-F1. Test accuracy, precision, recall, macro-F1, ROC-AUC, per-class scores and confusion matrices are saved. A separate drug-disjoint baseline audit measures harder generalization. The selected pipeline and global validation permutation importance are saved in `artifacts/model.joblib`; live inference uses that artifact. Molecular fingerprint importance is a statistical explanation, not a mechanism or causal attribution.

The dataset contains known interactions with severity labels, **not verified negative non-interactions**. The model predicts severity conditional on an interaction and cannot prove an unseen pair interacts or is safe. Scores are uncalibrated. Missing models or structures produce **unassessed** pairs rather than fabricated predictions. See [dataset documentation](docs/DATASETS.md) and [guideline coverage](docs/GUIDELINE_COVERAGE.md).

## Evidence and patient safety

Known DDI lookup, exact drug/class allergy checks, supported contraindication matches with explicit condition aliases, duplicate ingredients/classes, ADR association lookup and polypharmacy prioritization are separate from ML. Patient history and age/sex are recorded; unsupported factors do not automatically increase clinical severity. Daily dose totals are screened against verified reference ceilings for paracetamol (age 12+) and ibuprofen (adults). Repeated matching ingredients are aggregated. Other medicines and pediatric regimens receive explicit dose-review alerts. These ceilings do not establish a patient-specific safe dose; formulation, route, weight and indication are not yet captured.

The official DDInter bulk file includes IDs, names and severity but no mechanism/management fields. Imported alerts say those details are unavailable, rather than inventing them. Thirteen optional educational drug/brand/safety fixtures are visibly labeled as demonstrations. Brand composition must be checked against the actual product. Dataset medicines without class/condition annotations do not receive unsupported rule-based safety claims.

FAISS indexes normalized TF-IDF evidence vectors, retrieves matching interaction/ADR records, then an optional LLM explains those records or answers general educational questions. Sources and mode are shown. General questions reach OpenRouter even without local evidence and are labeled educational. Prescription-specific claims must use supplied evidence. Missing API keys or provider failures return an actionable notice. Current prescription context is scoped to the authenticated user. No dosage recommendations or diagnoses are requested from the LLM.

## Deployment

Build with `npm run build`; Express serves `frontend/dist`. Run the API and AI service separately behind an HTTPS reverse proxy. Set the frontend origin to the deployed origin, use a dedicated MongoDB database, configure secrets server-side, and expose only the public Express API. Do not expose the AI port publicly. The current binding is loopback; adapt the bind address for your deployment environment. No public deployment is created by this local rebuild.
